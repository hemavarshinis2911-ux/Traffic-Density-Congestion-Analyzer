# Traffic Density & Congestion Analyzer 🚦

## 📌 Project Overview

Traffic Density & Congestion Analyzer is a Java-based software project that uses OpenCV and YOLOv5 to detect vehicles from traffic images and analyze the level of traffic congestion.

The system detects vehicles such as cars, motorcycles, buses, and trucks, counts them, and classifies the traffic condition as Low, Moderate, or High.

## 🎯 Objectives

- Detect vehicles from traffic images
- Count different types of vehicles
- Analyze traffic density
- Identify traffic congestion
- Display the analysis through a Java GUI
- Generate an image with detected vehicles highlighted

## 🛠️ Technologies Used

- Java
- OpenCV
- YOLOv5
- OpenCV DNN
- Java Swing
- Eclipse IDE

## ⚙️ How It Works

Traffic Image
↓
YOLOv5 Vehicle Detection
↓
Vehicle Classification
↓
Vehicle Counting
↓
Traffic Density Analysis
↓
Traffic Level & Congestion Status

## ✨ Features

- Traffic image selection
- AI-based vehicle detection
- Vehicle counting
- Detection of cars, motorcycles, buses, and trucks
- Traffic density classification
- Congestion detection
- Graphical User Interface
- Detection result image generation

## 📊 Traffic Classification

| Vehicle Count | Traffic Level |
|---|---|
| Low | LOW |
| Medium | MODERATE |
| High | HIGH |

## 🖥️ Output

The system displays:

- Number of cars
- Number of motorcycles
- Number of buses
- Number of trucks
- Total vehicles
- Traffic level
- Congestion status

It also generates an output image with bounding boxes around detected vehicles.
